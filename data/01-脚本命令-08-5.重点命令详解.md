### 5.5 SUM

来源：`游戏引擎反外挂系统/其他相关资料/传奇基础脚本命令详解[!].htm.txt`

```
sum 变量A 变量B ;变量求和不要与int混淆,需要下面的组合语名才能实现

MOV 变量X 0 ;变量X，初值。

sum 变量A 变量B ;X=A+B

sum 变量C ;X=X+C 最后在程序中得到的是X值，实际X=A+B+C

;如果只写中间一句是无意义的，只能导致错误
```

同页另一处（照抄）：

```
sum (变量A) (变量B) ;A+B 注意,如果还要家第3个数直接换行写sum (变量C)

注:关于SUM的详解

首先有MOV (变量X) 0 ;(变量X)清0

sum (变量A) (变量B) ;X=A+B

sum (变量C) ;X=X+C
```
