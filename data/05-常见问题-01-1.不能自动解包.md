## 1. 不能自动解包

**问题**：物品（药品、卷轴等）打包后不能自动解包。

**原文原因/解法**：

- 客户端自动解包配置：**药品数据库的 `Anicount` = 打包物品的 `Shape`**，这样才可以自动解包。
- 例如：`强效金创药 Anicount=100` / `超级金创药 Shape=100`；`疗伤药 Anicount=115` / `疗伤药包 Shape=115`；`回城卷 Anicount=108` / `回城卷包 Shape=108`。
- 支持 2 次打包，例如可以把“疗伤药包”再次打包：`疗伤药包 Anicount=120` / `超级疗伤药包 Shape=120`。
- 解包配置文件 `Envir\UnbindList.txt` 格式，**兼容旧格式**，升级新 M2 如果不需要修改解包数量的，可以不修改 `Envir\UnbindList.txt`。
- 文件格式（原文注释）：`;物品DB字段shape的值 物品名称 解包数量 物品类型(0其他,1加红,2加蓝,3加红蓝,4卷轴)`
- 原文给出的 `Envir\UnbindList.txt` 示例（照抄）：

  ```
  100 强效金创药 6 1
  101 强效魔法药 6 2
  119 强效太阳水 6 3
  120 万年雪霜 6 3
  102 金创药(小量) 6 1
  103 魔法药(小量) 6 2
  104 金创药(中量) 6 1
  105 魔法药(中量) 6 2
  106 地牢逃脱卷 6 4
  107 随机传送卷 6 4
  108 回城卷 6 4
  109 行会回城卷 6 4
  ```

- 3.药品支持自动二次解包（以下为参考数据库资料），原文给出的 DB 行为（照抄，字段以制表符分隔）：

  ```
  1383	超级金创药包	31	110	20	0	1	0	313	0	...（后略）	3000	5	255	0	...
  189	超级金创药	31	100	20	110	1	0	1473	0	...（后略）	3000	5	255	0	...
  175	强效金创药	0	0	3	100	0	0	28	10	180	0	...（后略）	150	5	255	0	...
  ```

  原文对应给出的 `UnbindList.txt` 行为 `110 超级金创药 2`、`100 强效金创药 3`。

- 该页末尾另附「内挂默认药品设置」内容（与 `内挂默认药品设置.html.txt` 重复），见下一条。

**来源页面**：`不能自动解包.html.txt`

## 2. 登陆游戏黑屏

**问题**：登陆游戏黑屏。

**原文原因/解法**（原文列 3 条）：

1. 有可能是开的游戏网关(RunGate)有相同的端口。解决方法：在**控制器->配置向导->网关设置**中调整设置。
2. 有可能是由于开了防火墙或者安全策略把你游戏网关(RunGate)端口给屏蔽了。解决方法：开放所要用到的端口。
3. 使用的登陆器和引擎不配套导致黑屏。

**来源页面**：`登陆黑屏.htm.txt`

## 4. 内挂默认药品设置

**问题**：内挂（外挂内挂/默认挂机）的默认药品如何用数据库字段区分类型。

**原文原因/解法**：

- **数据库指定字段(Horse)**设置如下为内挂默认药品（照抄）：

  ```
  1.普通HP药水
  2.特殊HP药水
  3.普通+特殊HP药水
  4.普通MP药水
  5.特殊MP药水
  6.普通+特殊MP药水
  7.HP/MP特殊药水
  8.普通HP药水+普通MP药水+特殊HP药水+HP/MP特殊药水
  9.特殊HP药水+HP/MP特殊药水
  ```

- 及时雨内挂默认对应如下（照抄）：
  - 第一个 HP 为普通HP药水，数据库字段：`1、3、8`
  - 第二个 HP 为特殊HP药水，数据库字段：`1、3、8、9`
  - MP 为普通MP药水，数据库字段：`4、6、8`
  - HP/MP 为 HP/MP特殊药水，数据库字段：`7、8、9`
- 默认内挂对应（照抄）：
  - `1.普通体力药`
  - `4.普通魔法药`
  - `2.7.9特殊体力药`（触发内挂吃药后只要背包中有 2 和 7 和 9 的药品自动吃）
  - `5.7.9特殊魔法药`（触发内挂吃药后只要背包中有 5 和 7 和 9 的药品自动吃）
- 如果你使用仿及时雨内挂不想将药品区分太多：药品字段全部设置 `8`，或者普通HP和MP设置 `8`，特殊HP和特殊HP/HP设置 `9`。
- 如果你使用默认内挂：普通药的字段设置 `1` 和 `4`，特殊药不想区分太细就全部设置 `9`。
- 该文件后半段另附「客户端自动解包配置」内容（与 `不能自动解包.html.txt` 重复）：客户端自动解包配置，药品数据库的 `Anicount` = 打包物品的 `Shape`；并注明「默认药品支持同时支持物品分类号：**2类、31类**」。

**来源页面**：`内挂默认药品设置.html.txt`

## 5. 泡点功能详解

**问题**：如何实现在线泡点（挂机得游戏点）。

**原文原因/解法**：

- 泡点功能：可以实现人物在**线时间隔指定时间自动得到指定游戏点数**，这些点数可以用来换取物品、经验、等级或其它。
- 实现方法：泡点是**基于地图的**，可以指定哪些地图可以有泡点功能，人物进入此地图后就会自动增加点数。时间越长得到的点数就越多。
- 地图配置文件 `MapInfo.txt`，以比奇省图为例（照抄）：

  ```
  [0 比奇省 0]
  INCGAMEPOINT(60/1)
  ```

  此设置代表人物在比奇地图中时，60 秒会自动得到 1 个游戏点。
- 通过脚本玩家可以查到自己的游戏点数及兑换经验，原文示例（照抄）：

  ```
  [@main]
  当前系统时间<$LOGINTIME>，<你进入游戏时间>为：<$LOGINLONG>\
  <$USERNAME>您好根据您进入的时间所累计的<$GAMEGOLDNAME>有<$GAMEPOINT>点\
  <当前等级>：<$LEVEL>级
  <当前PK点数>：<$PKPOINT>点，<泡点点数>：<$GAMEPOINT>点\
  <当前声望>：<$CREDITPOINT>点
  <当前经验>：<$EXP><当前升级经验>：<$MAXEXP>\
  \
  『<兑换经验/@GetExp>』--每100个游戏点可以换经验100W\
  \
  〖<返回/@back>〗
  〖<关闭/@exit>〗
  [@GetExp]
  #if
  CHECKGAMEPOINT > 100
  #act
  CHANGEEXP + 1000000
  GAMEPOINT - 100
  #say
  兑换成功
  #ELSESAY
  你都没100游戏点数!!!
  <返回/@main>
  ```

**来源页面**：`泡点功能详解.htm.txt`

## 6. 如何改变蜡烛类型装备掉持久类型

**问题**：蜡烛类物品（蜡烛、火把）的掉持久方式如何自定义。

**原文原因/解法**：

- 功能：自定义蜡烛物品掉持久控制，**支持按时间掉持久或与普通装备一样受攻击掉持久**。
- 用法（照抄）：
  - 按时间掉持久：物品数据库中 `Source` 字段为：`０`（原文用的是全角零）。
  - 受攻击掉持久：物品数据库中 `Source` 字段为：`１`。
- 修改蜡烛、火把的持久值为亮度，`10000` 持久亮度为 `1`，最高亮度 `5`，会根据持久的降低，降低亮度。

**来源页面**：`如何改变蜡烛类型装备掉持久类型[!].htm.txt`

## 8. 商铺购买不了元宝

**问题**：商铺中买“金币、元宝、声望、经验”类物品时，没有给用户一个物品。

**原文原因/解法**：

- 商铺中的金币、元宝、声望、经验等等：如果数据库中的**物品名称以金币、元宝、声望、经验等等开头**的，购买时不是给用户一个物品，而是**根据物品的 `Need` 字段值直接给用户加点数**。
- 例：`元宝100` 这个物品，用户购买时，会根据这个物品的 `Need` 字段值直接给用户加元宝。
- 如果想要给用户一个物品，可以把物品名称改成 `100元宝`。

**来源页面**：`商铺购买不了元宝.html.txt`

## 10. 为什么我的 NPC 不能买、卖、修理物品？

**问题**：NPC 不能买、卖、修理物品。

**原文原因/解法**：

- NPC 脚本的**第一行**加上指定的操作，就可以正常了。
- 原文示例（照抄）：

  ```
  ;=================================
  (@buy @sell)
  %100
  +5
  +6
  [@main]
  欢迎光临！！！
  <买/@buy>\
  <卖/@sell>\
  \
  <关闭/@exit>
  ;================================
  ```

- 功能标志说明（照抄）：

  ```
  ;买物品
  @buy
  ;卖物品
  @sell
  ;炼药
  @makedrug
  ;存仓库
  @storage
  ;取仓库
  @getback
  ;升级武器
  @upgradenow
  ;取回升级武器
  @getbackupgnow
  ;修理
  @repair
  ;特殊修理
  @s_repair
  ;发祝福语
  @@sendmsg
  ```

## 11. 为什么我的沙城墙没血条

**问题**：沙巴克城墙没有血条。

**原文原因/解法**（原文分两步）：

1. 首先检查 M2 启动有没报错，如有检查怪物数据库(`Monster.DB`)有没设置城墙类型怪物名称，如没只需将城墙名称与怪物数据库相对应即可解决。错误信息如下：
   `[错误信息] 城堡初始化城门失败，检查怪物数据库里有没城门的设置: MainDoor，`
2. 检查怪物数据库内城墙名称的血量，**不能超过 5000**。

## 12. 为什么我原来数据库里的武器加速，现在乱了？

**问题**：数据库格式改变后，原数据库里的武器加速数据乱了。

**原文原因/解法**：

- 由于数据库格式有些改变，原数据库里组合数据字段会有所变化，大家按以下规则改一下数据就行了。
- 武器 `5,6`（`AC2`）准确；`MAC2`：`1-10` 为攻击速度减，`11` 或以上为攻击速加，点数为 `x - 10 = 1`。

## 13. 物品不能重叠

**问题**：物品不能重叠（叠加）。

**原文原因/解法**：

- 物品重叠功能**不能使用在拥有持久、属性、品质、纯度等物品上**。`StdMode` 等于 `0, 2, 3, 40, 41, 42,46`。
- 物品重叠功能，`StdItem.DB` 中 `OverLap=1` 或 `2` 表示可以重叠，`0` 不叠加。
  - `OverLap=1` 重量 = 重叠数量 × 单物品重量 / 10
  - `OverLap=2` 重量 = 重叠数量 × 单物品重量
  - `OverLap=3` 重量 = 无论叠加多少个物品，重量为单物品重量
- `DuraMax` 必须大于 `1`。

**来源页面**：`物品不能重叠.html.txt`

## 14. 游戏中人物血和蓝数值不正确

**问题**：游戏中人物血量、魔法（蓝）数值不正确。

**原文原因/解法**：

- 打开 `\Mir200\!Setup.txt`，将相应数值修改成下面一样即可（照抄）：

  ```
  [Setup]
  LevelValueOfTaosHP=6
  LevelValueOfTaosHPRate=2.5
  LevelValueOfTaosMP=8
  LevelValueOfWizardHP=15
  LevelValueOfWizardHPRate=1.8
  LevelValueOfWarrHP=4
  LevelValueOfWarrHPRate=4.5

  ;以下是英雄的
  HeroLevelValueOfTaosHP=6
  HeroLevelValueOfTaosHPRate=2.5
  HeroLevelValueOfTaosMP=8
  HeroLevelValueOfWizardHP=15
  HeroLevelValueOfWizardHPRate=1.8
  HeroLevelValueOfWarrHP=4
  HeroLevelValueOfWarrHPRate=4.5
  ```

- 修改后人物的血量和魔法值均恢复官方默认值，可调整以上数值增加游戏中 hp 和 mp 值…建议使用默认值。

**来源页面**：`血量显示不正确.htm.txt`

## 16. 组队热键

**问题**：组队快捷键是什么、为什么有时不能用。

**原文原因/解法**：

- 组队快捷键 `Alt+W` 和 `Alt+S` 均为**快速组队热键**。
- `Alt+W` 和腾讯QQ冲突，如果开启QQ就无法使用此热键。
