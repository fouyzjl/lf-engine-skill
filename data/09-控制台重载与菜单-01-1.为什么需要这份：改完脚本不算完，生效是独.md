# 09 · 控制台重载与菜单（本端实测，2026-09-18）

> **来源等级 = ①（云服务器实际文件/进程实测）**。
> 全部 ID 由 `GetMenuString` 逐项读出后实发验证，**不是从二进制或社区资料推测**。
> 通用语义（`@ReloadNpc` 等）另有说明书依据，见文内标注。

---

## 1. 为什么需要这份：改完脚本不算完，"生效"是独立一步

LF 引擎**不会**自动感知 `Envir\` 下的文件变化。改完脚本必须**重载对应缓存**才生效；
整服重启能做到，但代价高（本端还**没有自启**，重启后不会自己起来）。

本文给出**不用重启**的重载办法，以及每一项到底覆盖什么。

---


## 2. 窗口拓扑（定位窗口的唯一正确姿势）

```
GameCenter.exe                                     ← 顶层进程
└─ 顶层窗口  TfrmMain
     「翎风引擎控制台-暗黑流派-01区 [D:\MirServer暗黑流派\]」
   └─ 子窗口 TFrmMain
        「暗黑流派-01区 [无限版]」                    ← M2Server 主窗体
```

三个必须记住的点：

1. **`TfrmMain`（GameCenter）与 `TFrmMain`（M2）只差一个字母大小写，是两个不同的类。**
2. M2Server 主窗体被「窗口嵌入到控制台中显示」选项**嵌成了 GameCenter 的子窗口** →
   `EnumWindows`（只枚举顶层）**永远找不到它**，必须对 GameCenter 顶层窗口再 `EnumChildWindows`。
3. 菜单挂在**子窗口 `TFrmMain`** 上（对该窗口 `GetMenu` 非 0），不在 GameCenter 顶层窗口上。

> 血泪教训：别人留下的 `D:\m2ctl\reload-npc-ui.ps1` 就是只 `EnumWindows` 找 `TFrmMain`，
> 所以从未定位成功过；它配的菜单 ID 表却是**对的**。

## 4. 怎么发

对 `TFrmMain` 子窗口句柄发：

```
SendMessage(hwnd, WM_COMMAND = 0x0111, (WPARAM)id, (LPARAM)0)
```

- **句柄每次进程重启都会变**，必须动态发现：类名 `TFrmMain` + 标题含 `[无限版]`。
  不要写死句柄。
- 菜单项 ID 为 `-1` 的是**下拉父项**（如 `重新加载(&R)` 本身），不能发。

### 4.1 从 SSH 侧发（Session 0 → Session 2）

SSH 落 **Session 0**，游戏进程在 **Session 2**，`EnumWindows` **不跨会话** → 必须建
带 `/IT` 的一次性计划任务把脚本送进 Session 2：

```powershell
schtasks /Create /TN M2_XXX /TR "powershell -NoProfile -ExecutionPolicy Bypass -File D:\m2ctl\xxx.ps1" `
         /SC ONCE /ST 00:00 /RU Administrator /IT /F
schtasks /Run /TN M2_XXX
# ... 等结果文件 ...
schtasks /Delete /TN M2_XXX /F        # 用完即删
```

### 4.2 五个必踩的坑（每个都真实卡过一次）

| 坑 | 现象 | 解法 |
|---|---|---|
| `New-Object IO.MemoryStream($bytes)` | `找不到"MemoryStream"的重载，参数计数为:"1053"` | **必须写成 `New-Object IO.MemoryStream(,$bytes)`** —— 不加逗号 PowerShell 会把 byte[] 摊平成 N 个参数 |
| 落盘 `.ps1` 无 BOM | 脚本里的**中文路径/匹配串全废**（按 GBK 解码） | `[IO.File]::WriteAllText($p,$s,(New-Object Text.UTF8Encoding($true)))` |
| `-EncodedCommand` 超长 | `命令行太长。`（GBK 字节 `c3fc c1ee d0d0 ccab b3a4 a1a3`） | cmd 上限 **8191 字符**；大脚本 **gzip + base64** 压进去，外层解压落盘 |
| 计划任务没有 stdout | 脚本"跑了"但什么都拿不到 | 脚本内部 `Set-Content D:\m2ctl\*.out -Encoding UTF8`，外层再读回来 |
| SSH 连着开 | `kex_exchange_identification: read: Connection reset by peer` | sshd 限流，**相邻两次连接间隔 ≥ 2 分钟**（游戏本身不受影响） |

## 7. 与说明书对照

- 说明书 `其他相关资料/GM管理命令[!].htm` 列有 `@ReloadNpc`「重新加载NPC脚本」、
  `@ReloadManage`「重新加载登录脚本」、`@ReloadMonItems`「重新加载怪物爆物品列表」、
  `@ReloadItemDB`「重新加载物品数据库」等。
- **本端 `Envir\AdminList.txt` 是 0 字节（无 GM）** → 这些 `@` 命令**无法在游戏内使用**，
  只能用控制台菜单（本文的方法）。
- 说明书 `UpDate.htm` 有多条重载相关的历史修正（如"修正重新加载NPC后，QFunction-0
  字段触发引擎会报错"），可作为"NPC 重载**不包含** QFunction-0"的旁证。
