## 3. 存放位置与命名规律

以下**全部为原文明确写出的路径/文件名**，原文怎样写就怎样记（大小写不统一属原文如此）：

| 原文写出的脚本文件/位置 | 出现在哪些页面 | 原文写法（照抄） |

原文体现出的命名/书写规律：

1. **主目录的触发几乎都落在 `QFunction-0.txt`**：原文对它的写法有四种变体 —— `QFunction-0.txt`、`QFunction-0`（无扩展名）、
   `QFunction-0脚本里[@UsePlugin]字段`、以及带完整路径的 `...\Mir200\Envir\Market_Def\QFunction-0.txt` /
   `...\Mir200\Envir\market_def\QFunction-0.txt`（`Market_Def` 与 `market_def` 大小写不一致）。
2. **`兼容HeroM2/` 下的触发写在 `Q-Function.txt`（原文也写作 `Q-Function`）**，与主目录的 `QFunction-0.txt` 写法不同；
   原文没有说明两者的对应关系。
3. **目录层级**（原文出现的路径片段）：`Mir200\Envir\` 下直接放 `MapEvent.txt`；`QuestDiary\数据文件\` 下放名单文件
   （`H.CHECKNAMELIST ..\QuestDiary\数据文件\英雄名单.txt`）；`Envir\UserData\` 下放 `MapMagicEvent.txt`；
   `Envir\Market_Def\`（原文另一处写 `market_def`）下放 `QFunction-0.txt`。
4. **很多触发原文根本没写文件位置**，只写「QF触发」「QF字段」「触发字段」；其中 `个人商店名字过滤触发` 明确写
   `触发字段在当前npc的脚本内`（`@ShopNameFilter`）。
5. **触发名与段名的写法也不统一**：有的写 `[@XXX]`（方括号），有的写 `@XXX`（无方括号），同一页面内两种写法混用
   （如 `沙巴克行会触发.htm.txt`、`货币改变触发.htm.txt`、`套装触发.htm.txt`）。本文总表一律照抄该页面的写法。
6. **`MapQuest.txt`：这 60 个页面中原文完全未出现**，也未出现任何「任务脚本」目录的描述。

## 4. 未验证 / 存疑（原文没写清楚或自相矛盾之处）

以下均为**原文自身**的问题，或原文未交代而需要实测确认的点；本笔记不做推断、不补全。

### 4.1 原文自相矛盾

1. **攻击触发**（`攻击触发.html.txt`）：正文写 `;所有触发只有攻击到怪物才会触发，有些魔法不会触发，如魔法盾`，
   但同一段示例里却有「你被人物【…】攻击了」「你被英雄【…】攻击了」「你被分身【…】攻击了」等**非怪物**分支。
   两者直接冲突。
2. **魔法 ID 变量拼写不一致**：`攻击触发.html.txt` 中 `[@MagicAttack]`/`[@Struck]` 的怪物分支写作 `<$CURRRUSEMAGICID>`（两个 R），
   而 `[@Attack]` 的怪物分支原文写作 `<$CURRRRUSEMAGICID>`（三个 R）。是否为笔误、哪个正确，原文未说明。
3. **货币改变触发**（`货币改变触发.htm.txt`）原文自带不确定表述：`提示：可能 仅限脚本命令操作时触发` —— 文档自己也不确定。
4. **GOTOLABEL 触发**（`GOTOLABEL触发[!].htm.txt`）标题与正文格式写 `GOTOLABEL 模式(0,1,2,3)`，但后文把模式扩到 4-9，
   20200925 又增加模式 8，且第 81 行残留 HTML 转换碎片 `br>`；模式数量与括号里的 `(0,1,2,3)` 不一致。
5. **地图事件触发**（`地图事件触发.html.txt`）写 `;和翎风不同的我们这里增加一个范围`，主语「我们」「翎风」指向不明；
   组队条件标注 `(暂时不支持)`，即该列存在但实际无效。
6. **人物死亡时触发**（`人物死亡时触发.htm.txt`）第一段示例直接以 `#IF KillByHum` 开头，**没有段落名**，
   到文末才出现 `[@PlayDie]`；且 `<$HumKiller>` / `<$MONKILLER>` 与 `<$KILLER>` 的关系只以文字描述，未给完整对照。

### 4.2 原文写法可疑（照抄未改，需实测）

1. `走路或跑步触发.htm.txt` 示例用的是 `#SAT`（不是 `#SAY`），原文如此，疑为笔误。
2. `切换攻击模式触发.html.txt` 的段名是 `@AttatckModeChange`（原文拼写），疑为 `Attack` 之误，本文照抄。
3. `带上物品时触发[!].htm.txt` / `取下身上物品时触发.htm.txt` 的条件写作 `CheckLevelEx > \n0`（换行断开），
   脚本能否成立未说明。
4. `英雄死亡触发.htm.txt` 示例中 `<$HeroKiller> .GAMEGIRD + 10` 与 `<$HeroKiller> .SendNewLineMsg …`
   在变量与命令之间带空格和点，语法是否有效原文未说明。
5. `英雄上线触发.htm.txt` 里 `H.gender man` 与 `H.gender WOMAN` 大小写不一致，且 4 组同名条件
   （`H.ISNEWHUMAN` + `H.gender`）连续排列、装备不同，判断顺序如何生效未说明。
6. `商铺赠送物品前触发.htm.txt` 用 `StopShopItem` 中止「赠送物品」，而 `StopShopItem` 在
   `个人商店物品上架触发、下架触发.html.txt` 中是「停止个人商店物品上架/下架」命令，语义是否通用未说明。
7. `界面帮助按钮触发[!].htm.txt` 的 `[@Help]` 段正文只写 `Help`，含义未说明。
